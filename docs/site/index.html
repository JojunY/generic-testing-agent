The cast

Four agents. gtaw is the referee.

gtaw calls no model.

01 · The one you talk to

gta-orchestrator

It takes /gta and asks gtaw what to do next.

02 · Reads the code

gta-analyst

It writes the candidate spec for one flow.

03 · Writes one test

gta-test-author

It writes one test from the locked spec.

04 · Judges, and does not edit

gta-reviewer

It gives one verdict and does not edit the test.

What they must not do

The orchestrator does not edit files, answer for you, or run git or mvn.

The analyst cannot mark a source as confirmed.

The author does not change src/main and does not add @Disabled.

The reviewer is read-only.

 What the repository contains

          
Counts from this repository.

          

            
4named agents, each with one job

            
4layers a scenario can ask for

            
1program allowed to say a test passed

            
20skills shipped in core/skills

          

          

            What the counts mean
            
The layers are unit, slice, component, and contract. gtaw does not schedule system.

            
The 20 skills are the directories in core/skills. Mutation on unit and slice tests is advisory unless the project turns it on.

          

          

            Where tests run
            
gtaw and the tests run on your machine. A model request depends on Copilot or OpenCode and on the provider.

            
Each test drops cloud credentials and Spring profiles. Kafka and JMS run embedded. BigQuery, GCS, Oracle, and Pub/Sub use fakes or a shared test schema.

          

          

            Versions
            
Spring Boot 2.2 to 4.1. Services can use Java 8 or newer. gtaw needs JDK 17 or newer.

          

        

      

    


    

      

        
Install

        
Build it once. Then the command is /gta.

        
Build gtaw from this repository. Then run /gta in the service.

        
A published jar
A published jar needs a pinned URL and checksum. gtaw does not download an unpinned jar. The quickstart has the notes.
