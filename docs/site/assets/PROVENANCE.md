# Hero plate

`gta-cinematic-orbit-hero.jpg` is the original image supplied for this page. It is an original generated picture of a copper-coloured planet, a thin atmosphere, and a small spacecraft. It is scenery for the introduction. The spacecraft is not a gta product, and the picture is not a frame from the reference recording.

The WebP and AVIF files are encodings of that image. `hero-1920` is a resize of the 1280×720 original. `hero-portrait` keeps the same picture and extends the black sky above it so a tall screen can put the words on the sky and leave the planet and the craft in view.

Do not replace these files with art copied from the reference site.
